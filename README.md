# Quiet Library

도서관의 차분한 분위기에서 공부와 독서에 몰입할 수 있도록 만든 무료 웹 집중 타이머입니다.

🔗 [사이트 방문하기](https://quietlibrary.kr/)

## 주요 기능

- 원하는 집중 시간을 분 단위로 직접 설정
- 30분 · 60분 · 90분 빠른 시간 선택
- Dark / Light 서재 테마 선택
- 필기소리 재생, 끄기 및 음량 조절
- 일시정지와 메인 화면으로 돌아가기
- 타이머 완료 시 축하 화면 표시
- 설정 시간에 따라 크기가 달라지는 책 이미지 효과
- 사이트 소개, 기능 소개, 문의, 개인정보처리방침 독립 페이지
- 메뉴와 주요 이동 버튼 클릭 효과음

## 사용 방법

1. 첫 화면에서 원하는 분위기(Dark 또는 Light)를 고릅니다.
2. **도서관 입장하기**를 누릅니다.
3. 집중 시간을 직접 입력하거나 빠른 선택 버튼을 이용합니다.
4. **집중 시작하기**를 누르고 타이머와 함께 공부를 시작합니다.
5. 필요할 때 필기소리와 음량을 조절하거나 타이머를 일시정지할 수 있습니다.

## 기술 구성

별도 프레임워크나 빌드 과정 없이 HTML, CSS, JavaScript로 제작한 정적 웹사이트입니다.

- HTML5
- CSS3
- Vanilla JavaScript
- YouTube 임베드 재생기
- Vercel 정적 배포

## 로컬에서 실행하기

이 저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 확인할 수 있습니다. YouTube 필기소리는 브라우저의 자동재생 정책에 따라 사용자가 집중 시작 버튼을 누른 뒤 재생됩니다.

## Vercel 배포

1. 이 저장소를 GitHub에 올립니다.
2. Vercel에서 **Add New → Project**를 선택합니다.
3. 이 저장소를 연결한 뒤 배포합니다.
4. 별도 빌드 설정 없이 정적 사이트로 배포됩니다.
5. GitHub의 `main` 브랜치에 변경 사항을 올리면 Vercel이 새 배포를 진행합니다.

## 광고 및 개인정보 안내

Google AdSense를 이용하는 경우 `ads.txt` 파일을 사이트 최상위 경로에 유지해야 합니다. 개인정보처리방침은 [privacy.html](./privacy.html)에서 확인할 수 있으며, 광고 쿠키 및 YouTube 임베드 사용 내용을 안내합니다.
